# MangaiMart Shiprocket Tracking

A static, mobile-friendly order-tracking page ready for GitHub Pages.

## Live tracking

This frontend intentionally does not contain Shiprocket credentials. To display real shipment events, connect the form to a secure server-side endpoint that calls the Shiprocket API. Never place Shiprocket email, password, or API tokens in the browser.
